# Assets visuels

## Statut
- répertoire d'assets visuels extrait du traité
- blocs 1 et 2 alimentés

## Convention de nommage

```text
pXXX_figure_YY_description_courte.ext
```

- `pXXX` = page imprimée du traité, avec trois chiffres.
- `figure_YY` = numéro local de figure sur la page ou dans le bloc.
- `description_courte` = description ASCII, en minuscules, sans accents.
