# Glossaire

## Statut
- glossaire documentaire initial
- termes ajoutés pendant les blocs 1 et 2

| Terme | Définition | Source / portée | Statut |
|---|---|---|---|
| Page imprimée | Numéro visible dans le pied de page du traité. | Convention documentaire du projet. | utilisé |
| Page PDF | Numéro de page dans le rendu PDF du DOCX. | Convention documentaire du projet. | utilisé |
| Décalage de pagination | Dans ce document : page PDF = page imprimée + 1. | Vérification phase 0 et bloc 1. | utilisé |
| Source canonique | Fichier Markdown conservant fidèlement le contenu d'un bloc du traité avant synthèse ou dérivation. | Architecture `01_source_canonique/`. | utilisé |
| Front matter | Ensemble des pages préliminaires avant l'introduction : suivi, page titre, dédicace, citation, table des matières, remerciements. | Bloc 1. | utilisé |
| TODO / note auteur | Élément de travail ou note éditoriale à conserver sans le traiter comme fait validé. | Pages 0-1, 8 et autres blocs à venir. | utilisé |
| RDR | Réduction des risques ; cadre général de prévention et gestion des risques liés aux usages. | Bloc 2, p. 9-15. | utilisé |
| RdRD | Réduction des risques et des dommages. | Bloc 2, p. 13-14. | utilisé |
| TOC | Table of contents ; table des matières. | Pages 4-7. | utilisé |
| Prévention primaire | Prévention visant à éviter toute consommation de drogues. | Bloc 2, p. 9. | utilisé |
| Prévention secondaire | Prévention visant à réduire les risques encourus par les consommateurs ; niveau revendiqué du livre. | Bloc 2, p. 9. | utilisé |
| Prévention tertiaire | Prévention visant à réduire les conséquences de l'addiction. | Bloc 2, p. 9. | utilisé |
| Usage simple | Usage sans critères diagnostiques de trouble de l'usage selon la formulation du traité. | Bloc 2, p. 9-10. | à vérifier dans futurs chapitres |
| Trouble de l'usage | Catégorie diagnostique médicale mentionnée par opposition à l'usage simple. | Bloc 2, p. 9-10. | à compléter |
| Loi de Brandolini | Idée selon laquelle il est plus facile de propager une idée fausse que de rétablir la vérité. | Bloc 2, p. 10. | utilisé |
| Substance psychoactive | Substance active sur le cerveau ; le traité l'assimile dans une première approche à une drogue si prise en automédication ou récréativement. | Bloc 2, p. 12. | utilisé |
| Facilitation / provocation à l'usage | Catégories juridiques mentionnées dans le traité au titre de l'article L3421-4. | Bloc 2, p. 13. | extrait ; validation juridique requise |
| Présentation sous un jour favorable | Formulation juridique mentionnée pour les stupéfiants. | Bloc 2, p. 13. | extrait ; validation juridique requise |
| Gestion des risques et des plaisirs | Formulation associée à Energy Control pour décrire une approche opérationnelle de la RDR. | Bloc 2, p. 13. | utilisé |
| CAARUD / CARRUD | La source écrit `CARRUD`; le sigle devra être relu avant publication. | Bloc 2, p. 10. | à relire |
| CSAPA | Structure citée dans les publics associatifs/professionnels. | Bloc 2, p. 10. | utilisé |
| CND | Commission de l'ONU sur les stupéfiants, citée pour une résolution de mars 2024. | Bloc 2, p. 14-15. | à vérifier avant usage public |
