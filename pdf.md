## Quand utiliser le PDF

- Pour lire le traité d'un bout à l'autre (les signets du PDF permettent de sauter d'un chapitre à l'autre).
- Pour le conserver hors ligne.
- Pour partager une version complete.
- Pour garder la mise en page d'origine.

## Quand utiliser le site

- Pour chercher un mot-clé.
- Pour entrer par thème.
- Pour retrouver un chapitre ou une figure.
- Pour lire plus confortablement depuis un téléphone.
